# 国内期货全品种行情系统（Python + HTML）

一个本地运行的期货行情面板，数据源为**新浪财经**（公开接口），覆盖**国内全部期货品种**（上期所 / 能源中心 / 大商所 / 郑商所 / 中金所，共 5 大交易所、70 个品种）。顶部可在任意品种间切换，默认展示**纯碱 SA2701** 合约。

## 功能

版位参照新浪财经期货行情页：**左侧为行情图表，右侧为同品种各月份合约列表**。

- **品种切换**（顶部下拉，按交易所分组）：一次性列出国内 5 大交易所全部在交易品种，选择后自动载入该品种**主力合约**（成交量最大）
- **实时行情**（顶部，参照新浪）：现价、涨跌量、涨跌幅、时间，以及 最新价、开盘价、最高价、最低价、结算价、昨结算、持仓量、成交量、买价、卖价、买量、卖量（每 5 秒自动刷新；中金所无盘口字段，买/卖显示 `--`）
- **多周期 K 线**：分时、1 分、5 分、15 分、30 分、60 分、120 分、日 K、周 K、月 K、年 K
  - **分时**从夜盘（前一交易日 21:00）开盘起算至最新，与新浪一致，含均价线；周 K / 月 K / 年 K 由日 K 合成；120 分钟 K 由新浪分钟接口提供
  - **分时横纵轴自适应（参照新浪）**：横轴覆盖完整交易时段（夜盘开盘 → 收盘），当前时刻之后留白，随时间推进逐渐填满，刻度按整点显示；纵轴以**昨结算价为对称中心**上下自适应缩放（价格线始终居中），并画昨结算基准虚线，右下角成交量柱随横轴联动
- **主图指标**（叠加在 K 线上，选择器悬浮于主图右上角）：MA / SAR / BOLL / EXPMA / BBIBOLL
- **副图一**：成交量（柱）+ 持仓量（线）
- **副图二**（选择器悬浮于副图二区域右上角）：可切换 MACD / KDJ / RSI / BOLL / WR / DMI
- **同品种合约列表**（右侧栏，参照新浪）：只展示**当前在交易**的合约（按交割月份过滤，已到期合约不显示，且不遗漏），**按到期时间（交割月份）从近到远排列**，成交量最大的**主力合约**置顶并带“主力”标记，点击即可切换
- 多个副图联动缩放（滚轮 / 底部滑块），红涨绿跌（国内习惯）

## 使用说明

本项目是一个**本地运行的行情面板**：`server.py` 启动一个本地 Web 服务，浏览器打开页面即可查看全部品种与多周期行情。数据源为新浪财经公开接口，详见 [DATASOURCE.md](DATASOURCE.md)。

### 方式一：直接使用 exe（推荐，无需安装 Python）

从本仓库 **Releases** 下载 `FuturesQuote.exe`：

1. 双击运行 `FuturesQuote.exe`（会弹出一个命令行窗口，显示服务地址）。
2. 打开浏览器访问 **http://127.0.0.1:8100** 即可使用。
3. 关闭窗口即停止服务，使用期间请保持窗口开启。

> 说明：exe 为 Windows 单文件版本，不依赖 Python 环境；行情仍需联网访问新浪财经接口。

### 方式二：从源码运行（Python 3.7+）

环境要求：**Python 3.7+**（仅用标准库，无需安装任何第三方包）

```bash
cd sa2701-quote
python server.py
```

浏览器打开：**http://127.0.0.1:8100**

停止服务：关闭窗口，或在终端按 `Ctrl+C`。

## API

| 接口 | 说明 |
| --- | --- |
| `GET /api/varieties` | 品种总表（按交易所分组） |
| `GET /api/quote?symbol=RB2611` | 实时行情 |
| `GET /api/kline?symbol=RB2611&period=day` | K 线（period：line→分时由前端用 1 分合成；1/5/15/30/60/120/day/week/month/year） |
| `GET /api/contracts?variety=RB` | 同品种在交易合约列表（按交割月份从近到远） |

## 说明

- 数据来自新浪财经公开行情接口，可能有分钟级延迟，仅供学习参考，**不构成投资建议**。
- 中金所（IF/IH/IC/IM/T/TF/TS/TL）行情正常，但因新浪盘口字段格式不同，买价/卖价/买量/卖量暂不提供（显示 `--`）。
- 部分刚上市的新合约历史K线较短，年 K 数据较少属正常现象。
- 前端 ECharts 通过 CDN 加载，需要联网。
